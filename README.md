# AXIOM IQ — лаборатория мышления

Готовый адаптивный сайт-тренажёр когнитивных навыков. Запускается **без сборки, сервера, npm и базы данных**. Подходит для публикации на GitHub Pages.

## Быстрый запуск

1. Распакуйте ZIP-архив.
2. Откройте `index.html` двойным щелчком — сайт заработает локально.
3. Для размещения в интернете создайте публичный репозиторий GitHub (например, `axiom-iq`).
4. В репозитории нажмите **Add file → Upload files**. Загрузите **содержимое папки** `axiom-iq-site`, а не ZIP и не внешнюю папку: файл `index.html` должен лежать в корне репозитория.
5. Сделайте **Commit changes**.
6. Откройте **Settings → Pages → Build and deployment**: выберите **Deploy from a branch**, затем ветку **main** и папку **/(root)**. Нажмите **Save**.
7. Адрес сайта будет вида `https://ВАШ_ЛОГИН.github.io/axiom-iq/`. После публикации ссылка появляется в разделе Pages.

## Что работает

- 7 направлений: визуальные матрицы, числовые закономерности, логика, пространственные задачи, словесные аналогии, концентрация и зрительная память.
- 5 видов испытаний и отдельные тематические тренировки.
- Процедурная генерация многих заданий и несколько десятков тщательно составленных текстовых задач. Новые комбинации при каждом запуске.
- Четыре варианта ответа, проверка, объяснения, пропуск вопросов.
- Общий таймер в испытаниях, смена задания и завершение по времени.
- Результаты по категориям, история тестов, личный рекорд.
- Переключение тёмной и светлой тем, локальный профиль.
- Экспорт истории в JSON, полная очистка истории.
- Адаптивный интерфейс для мобильных устройств.
- PWA: после первого открытия по HTTPS сайт может работать без подключения благодаря service worker.
- Никакой отправки результатов на сервер и никаких регистраций.

## Структура

```text
axiom-iq-site/
├── index.html           # разметка и оболочка приложения
├── styles.css           # оформление, темы, адаптивность
├── app.js               # навигация, движок заданий, статистика
├── favicon.svg          # иконка
├── manifest.webmanifest # установка как веб-приложения
├── sw.js                # офлайн-кеширование (HTTPS)
├── .nojekyll            # совместимость с GitHub Pages
└── README.md            # эта инструкция
```

## Как изменять и расширять

- Заголовки, темы и типы задач: `CATEGORIES` и `MODES` в начале `app.js`.
- Вопросы с текстом: массивы `VERBAL_BANK` и `LOGIC_BANK`.
- Генерация заданий: функции `makeMatrix`, `makeNumeric`, `makeSpatial`, `makeAttention`, `makeMemory`.
- Внешний вид: переменные цветов в начале `styles.css`.
- При обновлении статических файлов измените `CACHE_NAME` в `sw.js` (например, с `v1` на `v2`), чтобы браузеры быстрее подхватили новый релиз.

## Важное уточнение об IQ

Проценты на сайте показывают долю верных ответов в заданиях тренажёра, **а не клинический или стандартизированный показатель IQ**. Достоверная шкала IQ требует нормирования на репрезентативной выборке, анализа сложности заданий и проверки психометрических характеристик теста. AXIOM IQ предназначен для тренировки мышления и отслеживания личного прогресса.

## Приватность

Профиль и результаты сохраняются через `localStorage` браузера; сайт не собирает аккаунты и не отправляет эту информацию в интернет. Очистка данных браузера удалит и историю. Для резервной копии используйте «Экспорт» в разделе «Моя статистика».

## Лицензия

Исходники проекта разрешено свободно изменять и публиковать для собственных нужд. Внешние библиотеки и шрифты не загружаются. Для оформления используются системные шрифты.
